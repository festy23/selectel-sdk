# S3: buckets и потоки объектов

`RegionalClient.S3()` выбирает `v2006_03_01` в явном account/project/region/pool
scope. Авторизация требует S3 material из `Config.Credentials`: SDK не использует
AWS default credential chain, IAM token или произвольно найденный AWS endpoint.
Подпись SigV4 использует service `s3`, region равен выбранному pool. Материал с
истёкшим `ExpiresAt` отклоняется до HTTP. Пустой expiry не является обещанием
неограниченного срока доступа.

## Адресация

`Bucket(name)` и `Object(bucketRef, key)` создают точные адреса без HTTP и без
утверждения о существовании. Для bucket используется S3-compatible подмножество
имён длиной 3..63 байта; object key — непустой UTF-8 длиной до 1024 байт.
Это не обещание поддержки всех более широких Swift/container имён. Ключ не
нормализуется: slash и dot segments сохраняются, URI escaping соответствует
закреплённому Smithy S3 serializer. XML DeleteMany отклоняет символы, которые
XML не может передать без изменения.

По умолчанию применяется path-style. `WithVirtualHosted()` возвращает новый
неизменяемый service view с адресом `bucket.regional-host`; старый view сохраняет
path-style. Это явный выбор существующего способа адресации bucket, а не
включение функции или миграция bucket. Selectel предупреждает, что включённую
virtual-hosted адресацию нельзя отключить. Refs обоих видов различаются kind,
сохраняют точный endpoint и parent. Все exact вызовы проверяют выбранный
endpoint; redirect и автоматический fallback запрещены. COPY допускает другой
bucket, проверяя scope и актуальность endpoint источника отдельно от назначения.

Встроенная карта содержит только опубликованные S3 endpoints ru-1/3/6/7,
gis-1, uz-2 и kz-1. Для kz-1 сохранён опубликованный домен `srvstorage.uz`.
Неизвестный pool требует явного подходящего endpoint override. Ref из старого
endpoint не переносится на новый override. `LocationConstraint`, если задан,
должен совпадать с выбранным pool. Полученные region/location — метаданные,
они не переключают scope.

## Операции и граница покрытия

13 remote core bindings предоставляют:

- `Buckets.Create/Head/Location/Delete`, `Buckets.ListPage/Iterate/Collect`;
- `Objects.Upload/Download/Head/Delete/Copy/DeleteMany`;
- `Objects.ListPage/Iterate/Collect` для v2 и варианты с суффиксом `V1`.

COPY поддерживает source ETag и source modified/unmodified-since conditions;
последние явно сериализуются как HTTP dates в UTC. DELETE поддерживает If-Match.
Эти условия закреплены текущей страницей Selectel conditional requests;
412 возвращает conflict и rejected Receipt без повторения mutation.

`PresignGet/PresignPut` используют те же ограниченные GET/PUT bindings, локально
подписывают запрос без HTTP и возвращают protected URL, protected signed headers
и точный `ExpiresAt`. Caller явно задаёт срок 1..900 целых секунд. Срок не может
выходить за известный expiry credential. PUT принимает известные upload headers;
GET принимает version/range/ETag conditions. Передача подписанного URL является
явной передачей доступа; автоматического reveal или печати URL нет.

Отдельный 14-й binding `objects.post` предоставляет локальный `PresignPost`,
15-й `objects.post_template` — `Buckets.PresignPostTemplate`.
Все 15 bindings имеют **partial** coverage: typed core subset не равен всему
upstream AWS API. Generated contracts содержат точный inventory input/output
полей закреплённого AWS SDK и список исключённых request variants. ACL mutations,
tagging, request payment и response overrides не пересылаются на основании
Selectel compatibility table. Остальные неподтверждённые AWS поля не объявляются
unsupported у Selectel: их evidence owner — #74, реализация P1 и приёмка #75.
Multipart относится к #45; bucket policies/settings/versioning/object-lock
варианты — к #46. В частности, ObjectLockEnabled при создании bucket не означает
реализацию retention/legal hold API. Несогласованность compatibility table с
более новыми Object Lock guides требует отдельной проверки источников.

`BucketListOptions.NativePagination` явно включает закреплённые AWS pagination
параметры ListBuckets; их текущая доступность на Selectel не подтверждена live.
Классический вызов не добавляет их молча. `coverage_ratio=null`, полный inventory
семейства не установлен. Каталог не делает wire/live verified claim.

## POST form policy

`Objects.PresignPost` принимает exact object ref и `PostOptions`: обязательный
Expires 1..900 целых секунд, MinBytes >= 0 и MaxBytes > 0, MinBytes <= MaxBytes.
Caller явно выбирает byte range; JSON сохраняет int64 без float conversion.
`Conditions` допускает только точные ContentType и user Metadata. Policy всегда
содержит точные bucket, key, алгоритм, дату, credential scope и session token,
если credential source его предоставил. Поля автоматически получают equality
conditions; произвольный JSON policy, prefix/key-template (`${filename}`), ACL,
redirect и переопределение auth/length constraints не предоставляются.

Результат содержит protected URL, Fields и base64 Policy плюс UTC ExpiresAt,
совпадающий с expiration в policy. Подпись HMAC-SHA256 вычисляется по base64 policy
через source-defined SigV4 key derivation. Path-style и virtual-hosted формы
сохраняют exact endpoint bucket; query/prefix/domain fallback отсутствует.
Сырой input и итоговая base64 policy ограничиваются Config.MaxJSONBytes.
Credential expiry дополнительно ограничивает lifetime. Это локальный presign:
HTTP, upload/file reader и Receipt отсутствуют; SDK не видит remote исход формы.
Caller передаёт Fields как form-data, затем **последним полем file**, согласно
инструкции Selectel. Reveal URL/fields/policy выполняет только caller в месте
передачи формы. Самостоятельная отправка формы не покрыта runtime retry/receipt;
последующее HEAD остаётся наблюдением exact адреса без доказательства записи.

```go
form, err := storage.Objects.PresignPost(ctx, object, s3.PostOptions{
    Expires: 5 * time.Minute, MinBytes: 0, MaxBytes: 1024 * 1024,
}, types.CallOptions{})
if err != nil { return err }
// form.Data.Fields и form.Data.URL остаются protected; SDK HTTP не выполняет.
_ = form
```

### Scoped filename template

`Buckets.PresignPostTemplate` — отдельный API для опубликованного Selectel
`${filename}` варианта. Он принимает exact bucket ref и `PostTemplateOptions`:
непустой UTF-8 Prefix длиной до 1013 байт, Expires/MinBytes/MaxBytes и те же
типизированные equality Conditions. Caller не передаёт placeholder: SDK
компилирует form key как Prefix + `${filename}` и единственное условие
`["starts-with", "$key", Prefix]`. Любое `${...}` внутри caller prefix запрещено.
Остальные bucket/auth/session-token/size/expiry conditions остаются обязательными.
Prefix не нормализуется; slash/dot segments, кавычки, Unicode и специальные
символы сохраняют точное значение через JSON escaping, а не превращаются в policy.

Этот scoped API сознательно не разрешает пустой prefix (доступ ко всем ключам
bucket), произвольные шаблоны, raw conditions или auth/redirect fields.
1013-байтный предел ограничивает передаваемый template до 1024 байт; фактическое
имя файла проверяет провайдер после expansion, и SDK не обещает его допустимость.
Результат — protected form inputs без exact object ref, Receipt, lookup/adoption
или creation proof. Caller знает bucket/prefix, но не итоговый object ID.
`Objects.PresignPost` сохраняет прежнюю exact-key проверку и не принимает
`${filename}` вместо ref. Оба варианта подписываются локально, без HTTP.

```go
form, err := storage.Buckets.PresignPostTemplate(ctx, bucket, s3.PostTemplateOptions{
    Prefix: "incoming/", Expires: 5 * time.Minute, MinBytes: 0, MaxBytes: 1024 * 1024,
}, types.CallOptions{})
if err != nil { return err }
// Передать protected form inputs по явному решению caller; file — последним.
_ = form
```

## Передача и ошибки

Upload принимает caller-owned `io.Reader` и точный размер. Для HTTPS PUT
применяется документированный S3 `UNSIGNED-PAYLOAD`, без буферизации всего объекта
и без требования seek. Размер ограничивает чтение; нулевой размер использует
известное пустое тело. Число прочитанных байт не доказывает сохранение данных или
проверку integrity. Download пишет в caller-owned `io.Writer` с явным MaxBytes,
сохраняет уже переданный prefix и ошибку при коротком теле, deadline, cancellation
или превышении лимита. SDK не закрывает reader/writer caller. Response body
закрывается при завершении или отмене; mutation не повторяется, download не
повторяется после начала выдачи данных.

HEAD/GET отображают точный ContentLength, ETag, raw provider LastModified,
protected content headers/metadata/version. HTTP 304 не выдаёт содержимое.
XML и diagnostic bodies ограничены общим structured limit. Provider Message
не возвращается; используются HTTP status и известный S3 machine code.
Ошибки optional diagnostics не отменяют общие retry/status/deadline правила.
HTTP 200 COPY с вложенным Error не считается успехом. DeleteMany сохраняет
точные per-item результаты; mixed errors возвращают partial_success, missing
non-quiet результаты — protocol_error с уже разобранным prefix.

Collections используют общий bounded pagination. V1 marker, v2 opaque
continuation и list filters входят в binding cursor; virtual-hosted cursor
привязан к bucket endpoint. EncodingType=url декодирует key/prefix, но не opaque
v2 token. Отсутствие NextMarker в truncated v1 допускает source-defined last-Key
fallback; отсутствие безопасного continuation завершает страницу ошибкой.
Полнота обхода не означает snapshot consistency. Common prefixes не усыновляются
как объекты. Provider count не превращается в total без такого source контракта.

## Пример вызова

`client` ниже создан с явным `Config.Credentials`; caller выбирает scope и
сам решает, куда передавать protected результат. Пример не запускается при
генерации или проверке каталога.

```go
project, err := client.Project(projectID)
if err != nil { return err }
regional, err := project.Location(region, pool)
if err != nil { return err }
storage := regional.S3() // WithVirtualHosted() — только явный выбор caller.
bucket, err := storage.Bucket(bucketName)
if err != nil { return err }
object, err := storage.Object(bucket, "reports/result.bin")
if err != nil { return err }
uploaded, err := storage.Objects.Upload(ctx, object, reader, byteCount,
    s3.UploadOptions{}, types.CallOptions{})
// Сохранить uploaded.Receipt даже при err; Unknown не повторять.
if err != nil { return err }
signed, err := storage.Objects.PresignGet(ctx, object,
    s3.PresignOptions{Expires: 5 * time.Minute}, types.CallOptions{})
if err != nil { return err }
// signed.Data.URL остаётся ProtectedValue: Reveal только по решению caller.
_ = signed
```

## Receipt и наблюдение

Каждая mutation сохраняет Receipt, включая ошибки после acknowledgement.
Caller-selected bucket/key ref — только requested address, не creation proof.
`Client.Resource/Resume` поддерживают exact S3 refs и валидируют schema, account,
revision, effect, scope и endpoint. Known accepted/rejected/not_sent outcome
можно восстановить conclusively без HTTP даже без refs. Unknown обычного
bucket/key изменения допускает только точное HEAD observation и остаётся
indeterminate: существование не доказывает авторство или содержимое.

Unknown DeleteMany и version-selected Delete не восстанавливаются через HEAD
текущего объекта: RecoveryUnavailable. Нет mutation replay, lookup по имени,
автоматического adoption, cleanup или скрытого multipart. Цели bucket/object
present/absent проверяют только существование/404; успешный Status имеет
Classification succeeded и ProviderState present. Wait не обещает integrity,
завершение replication, causal write proof или readiness без ref.

## Источники и проверка

Primary Selectel страницы и immutable upstream model snapshots перечислены в
[source README](../../../internal/s3contractgen/README.md). Generated extraction
является SDK-owned protocol contract, а не выдаётся за provider OpenAPI.
Общий synchronous response seam перенесён из reviewed Swift `8a07c83`; conclusive
receipt-only recovery — из reviewed `379458e`. Новые compiled S3 signing,
virtual-host derivation и presigning ограничены service/generation/operation,
не предоставляют caller-controlled raw executor или credential callbacks.

Проверка выполняется на публичном Client/scoped API с синтетическими credentials
и подменой только HTTP RoundTripper. Она включает все 13 core операций и локальные exact-key и scoped-template POST form bindings, независимую
HMAC проверку SigV4, URI escaping, presigning, virtual hosts, streams/limits,
exact refs/cursors, protected output и отрицательные response/error сценарии.
Это offline evidence; реальные credentials, buckets и S3 mutations не применялись.
