# Domain vocabulary


**selectelsdk**:
Общая библиотека программного управления облаком Selectel для агента или
приложения. Перенос инфраструктуры является одним из её применений.
_Avoid_: оркестратор миграции, политика автономности агента

**Каталог возможностей selectelsdk**:
Перечень операций библиотеки с их официальными контрактами, реализациями и
статусами проверки. Наличие операции в каталоге не означает право конкретного
пользователя выполнить её.
_Avoid_: список импортированных SDK, список разрешений пользователя

**Receipt selectelsdk**:
Сохраняемое подтверждение конкретного вызова изменения: исходный scope,
endpoint, факт отправки и принятия, известные ссылки и возможность восстановления.
_Avoid_: Terraform state, гарантия завершения ресурса, provider operation ID

**Неизвестный исход selectelsdk**:
Результат вызова, при котором облако могло применить изменение, но у вызывающей
стороны нет подтверждения. Не разрешает автоматическое повторение изменения.
_Avoid_: гарантированная ошибка создания, гарантированное отсутствие ресурса
