Создать бакет

Последнее изменение: 08 апреля 2026Открыть в Markdown

  1. В панели управления в верхнем меню нажмите Продукты и выберите S3.

  2. Перейдите в раздел Бакеты.

  3. Нажмите Создать бакет.

  4. Введите имя бакета. Для совместимости с S3 API имя бакета должно удовлетворять условиям:

    • быть уникальным среди бакетов всех пользователей, которые используют хранилище по S3 API и размещаются в том же пуле;
    • соответствовать правилам именования бакетов Amazon S3 — содержать только цифры, буквы латинского алфавита, символы . и -, подробнее в инструкции Bucket naming rules документации Amazon.

  5. Выберите регион и пул, в котором будет создан бакет.

  6. В блоке Конфигурация:

    6.1. Выберите тип бакета:

    • приватный — для хранения резервных копий и других данных с доступом по логину и паролю или авторизационному токену;
    • публичный — для раздачи контента сайта или веб-приложения, доступен без авторизации.

    6.2. Выберите класс хранения:

    • стандартное хранение — для хранения и раздачи часто запрашиваемых данных;
    • холодное хранение — для хранения редко запрашиваемых данных;
    • ледяное хранение — для хранения очень редко запрашиваемых данных. Доступно только в пуле ru-3.

    Класс хранения влияет только на стоимость ресурсов, технически и по скорости классы одинаковые. После создания бакета класс хранения изменить нельзя.

    6.3. Выберите тип адресации. Мы рекомендуем выбирать vHosted-адресацию для работы с S3 API. Изменить тип адресации на Path-Style после создания бакета нельзя.

  7. Опционально: в блоке Защита данных:

    7.1. Чтобы хранить предыдущие версии объектов, включите версионирование.

    7.2. Чтобы защищать объекты от удаления, включите Object Lock. Включение Object Lock не блокирует объекты автоматически — вы сможете управлять блокировкой объектов после создания бакета. Для работы Object Lock необходимо версионирование — если не включить его, оно будет включено автоматически.

  8. Нажмите Создать бакет.
